# D-Arena mobile app

Code export of the D-Arena Figma Make prototype (React 19 + Vite + Tailwind 4).

```bash
npm install
npm run dev      # local dev server
npm run build    # type-checks, then writes the static site to dist/
```

`dist/` is committed and built with a relative base, so once this branch is merged
GitHub Pages serves it at `/projects/d-arena/dist/`.

Photos load from images.unsplash.com, as in the Make file.
